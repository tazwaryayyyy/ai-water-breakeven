Do not add features.

One final instruction

Before writing code, study the current screenshot and identify every element that contributes to the generic dashboard / AI-generated aesthetic.

Do not blindly preserve the current component hierarchy.

Recompose it.

The current functionality is already good.

The problem is the visual voice.

Fix the voice.

The key change I would insist on is this: stop trying to make the simulator look like a “scientific instrument.” That phrase itself pushed the previous build toward fake labels, grids, status badges, and dashboard chrome. Make it look like a really good interactive research graphic instead. The data should create the visual identity, not the UI decoration. That is much closer to how strong data-journalism and information-design work treats charts: fewer graphics, stronger hierarchy, and annotations that explain the actual data rather than surrounding it with interface prose.
